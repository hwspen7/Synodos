# Fixed120: twelve-language real speech benchmark

Purpose: narrow the supported languages to 12 and freeze five authentic
single-speaker clips plus five authentic two-speaker conversations per language.
Total: 60 single-speaker + 60 dual-speaker = 120 distinct clips.

## Source and selection protocol

Singles: Google FLEURS, Hugging Face google/fleurs, validation split.
Select **zero-based row indices 113, 121, 129, 137, 145** of the
pinned validation Parquet for each locale, not rows previously selected
for the earlier Fixed150 test. Retain raw reference text, source row and
source sample id, canonical 16kHz mono PCM16 waveform, and its SHA256.

True dual-speaker meetings: David AI DAI-ASR-I18N, public evaluation
corpus, two synchronized source-speaker FLAC channels, per-speaker human-
verified transcripts and word timings. Read the pinned metadata table
data/<language>/<language>.parquet for each of the twelve languages.
Require two actual speakers and valid original speaker references.
Choose five clips using the 10th, 30th, 50th, 70th and 90th percentiles
of overlap fraction sorted in increasing order (sample ID as tie-breaker).
Selection does not read Whisper outputs, WER or reference text accuracy.
These 60 real conversations are NOT generated by concatenating unrelated
recordings. Create a mono playback/test mix locally by summing synchronized
tracks with peak safety. Keep speaker references and any pseudo-timing flags.

All row/sample IDs, source commit SHA, audio hashes, and annotations are
written locally and are never committed to GitHub. Actual DAI sample UUIDs
cannot be verified before licensed access; do not substitute fake IDs.

## Licensing and separation

FLEURS is released under CC BY 4.0, attribution required.
DAI-ASR-I18N is gated and requires an approved Data Use Agreement.
Evaluation/benchmarking is allowed including evaluation of commercial
models. Training, model optimization, biometric reidentification and
redistribution are prohibited. Retention/deletion terms must be followed.
Consequently, reserve DAI as a blind evaluation set, not a development
sample bank for repeatedly tuning the ASR model.

Request access and read the conditions at:
https://huggingface.co/datasets/davidai-labs/DAI-ASR-I18N

## Run on Windows PowerShell

Use an existing project Python environment containing huggingface_hub,
pyarrow, numpy, scipy and soundfile. The earlier Fixed150 environment
already used these dependencies. Route Hugging Face cache to the E: drive
if the C: drive is limited.

    $env:HF_HOME = 'E:\HF_cache'
    .\.venv\Scripts\python.exe tools\fixed120_prepare.py --source singles

This prepares the 60 public FLEURS single-speaker examples independently.
For the real-dialogue 60, first receive DAI authorization and log in:

    hf auth login
    .\.venv\Scripts\python.exe tools\fixed120_prepare.py --source multi

Only after all 120 files have passed checksum and reference validation:

    .\.venv\Scripts\python.exe tools\fixed120_prepare.py --verify

Results live only in benchmark/fixed120, which is Git-ignored.
Audio path: benchmark/fixed120/audio/
Source lock: benchmark/fixed120/lock.json
Single references: benchmark/fixed120/manifest_single.jsonl
Speaker-attributed real dialogue references:
benchmark/fixed120/manifest_multi.jsonl

Note: a baseline ASR score is not a release gate. Measure WER/CER
(language-appropriate normalization), diarization DER/cpWER, speaker count,
missed/duplicated text, overlap retention and real-time finalization latency.
Prohibit leakage from DAI speaker-attributed references into ASR prompts.
Keep original Fixed150 intact as historical regression evidence.
